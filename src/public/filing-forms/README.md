# 公式届出PDF

日本年金機構の様式掲載ページから2026-10-28に取得した未加工の原票。
配布URLとSHA-256は `sources.json` を参照。資格取得・喪失は2026年10月改訂の配布ファイル。
原票の2ページ目の注意書きを含めて保存している。

アプリは原票を複製して1ページ目の所定の欄に文字を重ねる。バーコードや記入上の注意は変更しない。
被扶養者が複数の場合は人数分の原票を複製し、注意書きは末尾に1回添付する。
様式を更新する際は必ず座標・ページ構成・文字位置を再検証すること。

## 日本語フォント

- 配布元: https://github.com/google/fonts/tree/main/ofl/notosansjp
- 取得元: https://raw.githubusercontent.com/google/fonts/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf
- 取得日: 2026-10-28
- `fonts/NotoSansJP-Regular.ttf`: 可変フォントをfontToolsでwght=400に固定した派生フォント。
- ライセンス: SIL Open Font License 1.1。`fonts/OFL.txt` を同梱。
- PDFに必要な文字が欠落しないよう、静的フォントを全文埋め込みする。

再取得スクリプト: `work/download-official-forms.py`。
生成検証: `node work/check-official-pdf.cjs`。実データへの書き込みは行わない。

## 記入例との配置照合（2026-10-28）

`work/pdf-reference-layout.py` に公式記入例9種類の配布URLを記録している。
桁枠は原票PDFのベクトル罫線から測定。日付・番号・報酬合計は1文字ずつセル中央に描画する。
基準線ではなくフォントの実際の字形範囲で中央を算出し、元号番号形式の生年月日、
右寄せ金額、氏名・フリガナ、電話番号の区切り位置を記入例に合わせる。

配置検証: `work/check-pdf-placement.py`。文字の枠内収容・印刷済みラベルとの重なり・
公式罫線に対する桁位置・画像化後の数字の中央位置を独立して確認する。

## 未登録項目の扱い

社員番号を被保険者整理番号とみなしたり、事業所番号を整理記号として使用しない。
未登録・不正・未対応の欄は空欄とし、画面の要確認一覧で案内する。
公式原票の採用と、すべての届出項目の入力・審査ロジックの完成は別である。
現時点で未入力欄を補完せずに提出可能であることを保証するものではない。
