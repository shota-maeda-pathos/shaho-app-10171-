# 機能カタログ チェックリスト

カタログ（第2版）の【】項目ごとに実装状況を管理する。`roadmap.md` の各段階は、このリストの該当項目を「確認済」にすることを完了条件とする。

## 状態の凡例

| 記号 | 意味 |
|---|---|
| ✅ | 確認済：実ブラウザーでカタログどおりに動作することを確認した |
| 🔵 | 実装あり：コード上は実装されているが、実ブラウザーで未確認 |
| 🟡 | 一部：実装はあるがカタログの要件を満たしていない |
| ❌ | なし |
| ❓ | 未調査 |

初版（2026-10-29）はコードの読み取りのみで記入した。段階1（同日）の改修分を反映。実ブラウザーでの確認はまだ行っていないため、✅は0件。「段階」はロードマップの段階番号。
